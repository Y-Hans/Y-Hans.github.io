# Yajat Hans — Portfolio

Static portfolio built with HTML, CSS, and vanilla JavaScript.

## GitHub Pages

GitHub Pages looks for an `index.html` entry file in the publishing source. For a personal site, create a repository named `Y-Hans.github.io`, upload the contents of this folder to the repository root, then enable Pages from the `main` branch and `/ (root)`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Files

- `index.html`
- `css/style.css`
- `js/script.js`

No build step or dependencies are required.
